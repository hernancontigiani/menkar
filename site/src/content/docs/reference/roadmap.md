None of this is in the current release yet.

## Use Codex and OpenCode sessions

Codex and OpenCode join Claude Code and Cursor, in the orchestration mode too: the orchestrator
can start them as workers, and they report to it as Claude Code sessions do.

## Run Menkar on macOS

After 1.0, Menkar comes to macOS as an experimental build: tested automatically on GitHub's
machines, not on a real Mac, and unsigned, so you open it by hand the first time.
