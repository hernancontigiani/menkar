## Talk to one session

Turn on [the orchestration mode](/menkar/orchestration/) in a project and choose an orchestrator.
Ask it for the work; it starts a worker per task, follows each one and reviews what comes back.
The workers run in the background, so your tab strip holds only the sessions you talk to.

## See what awaits you

The sidebar keeps at the top the items only you can answer, the current one first. Above the tabs,
[the Board](/menkar/orchestration/board/) shows every task with its steps and latest note.

## Keep every session in one window

Without the orchestration mode, Menkar is a window for all your Claude Code, Codex, Cursor and
OpenCode sessions: [tabs and panes](/menkar/sessions/tabs-and-panes/), projects, several windows, file tabs, and the
[time, tokens and cost](/menkar/usage/window/) of each session.

## Keep your work on your machine

Menkar runs the real agent in its terminal and reads its files without rewriting them. It makes no
network connection of its own: no telemetry, no update check.
[See what it keeps](/menkar/reference/privacy/).
